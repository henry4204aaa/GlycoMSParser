# Attribution — reference database content

The composition-to-structure entries (WURCS strings and GlyTouCan accession numbers) in the GlycoMSP reference
databases in this folder were obtained from the GlyCosmos Glycan Composition Converter API
(`https://api.glycosmos.org/glycancompositionconverter/1.0.0/composition2wurcs`) and the GlyTouCan repository.

**GlyTouCan / GlyCosmos composition data, CC BY 4.0 (https://glytoucan.org, https://glycosmos.org)**

Licence: Creative Commons Attribution 4.0 International — https://creativecommons.org/licenses/by/4.0/

Each database records its data source in its own metadata (`attribution`, `endpoint`), and every fetched entry
is listed in the transaction log with the endpoint it came from.

Entries with `source = user` are the user's own local annotations and are not GlyTouCan/GlyCosmos data.

## Showcase snapshots

A database published in this folder is a showcase snapshot of a database in use at the time of publication.
Later design or version changes of GlycoMSP may alter its structure and behaviour; no compatibility is promised.
