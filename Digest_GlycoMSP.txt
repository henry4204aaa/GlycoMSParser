GlycoMSParser

Project started in 2022 as my PhD research topic

Goal: Automatically parse/process mass spectrometry data to user-friendly and data-scientist-friendly format, support annotation (self-labeling with some predefined conditions - not 100% precise; import manually labeled data and automatically concat back to converted dataset so the annotation can link with proper spectral data), storing metadata on file/experiment/project level, use traditional ML method to train models that can recognize same glycans that user has registered (included in training dataset) under same experiment/instrumental condition, allow project management, allow accumulativing training datasets, allow adjustment of model parameters, able to share models, parameters and training dataset online


Novelty:
Advocate a easy-to-use and also human readable csv format for storing deconvoluted(by the library or package made for processing original mass spec raw data) spectral data

Semi-automated workflow from beginning dataset to ML-ready data

Adjustable ML parameters and traceable operation logs (can be shared and reproduce in a similar level on different devices)

Help users to accumulate high quality annotated glycan mass spectral data for further multi-omics research


Key points:

*Treat fragmentation ions as features to reduce the complexity when performing ML
*Provide a pseudo labeling (fit composition from precursor mass) that filter glycan-like spectra to reduce the time spent for user investigating unexplored datasets
*All datasets and operation logs, trained models themselves are saved and allowed to export/load in our software so the validation become possible (note that ML methods have randomness so the same datasets trained on other devices may show slight difference)




What we've finished

Read and convert raw data to proper csv format obtained from ThermoFisher MS instruments

Build a GUI for user doing:
- file conversion and generate metadata
- load converted file and manage as specimen in experiment, project
- bind with manual annotation data
- export ML ready dataset for training/convert unlabeled data to ML test ready format
- toggle ML training and testing window

Some reference

- CandyCrunch: DL tool gathering public database and trained a model for identifying glycans. I tested it and noticed the source training sets are likely rubbish. Not applicable to real biological data unless you want a very general result. Can't trace back to certain spectra since it only outputs summary report

- GlycReSoft: Database support and automatically solve MS spectra and label as certain composition based on user search settings. Unable to provide certain fragmentation ion information of spectra. 

- SimGlycan: made by sciex, may already provide similar features as we're making
https://sciex.jp/content/dam/SCIEX/pdf/tech-notes/all/mass-spectrometry-cms_053912.pdf
