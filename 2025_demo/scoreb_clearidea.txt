0) Inputs and outputs
Inputs per run

Excel path

User flags (dict): e.g. {"AllowABH": True, "AllowLewis": True, "Allow5Ac": False, ...}

Spectrum for one MS2 scan:

peak m/z array

peak intensity array (or a prebuilt peak lookup structure)

Candidate composition string for that spectrum: e.g. H6N5F1S0 (one at a time in your existing loop)

Global settings:

ppm tolerance

intensity handling: hit_mode = "binary" or "log10"

optional: min intensity threshold, floor for log10

Output per candidate composition

scoreB_total (float)

breakdown:

motif scores E(m) and their matched ions (top N for debug)

consistency penalties applied (S=0 etc.)

optionally “predicted motifs” = motifs ranked by evidence score

1) Excel loading and normalization layer
1.1 Load sheets

Load these into DataFrames:

ionlist

1.2 Build canonical columns

Normalize column names to a stable internal schema (do this once):

ionlist:

ion_struct_id ← Structural identifiers

mz ← Fragmentation mass

optional: charge_mode, derivatization

interpretation_v2:

target_id, ion_struct_id, ion_role, logic, min_hits, weight, charge_mode_required, derivatization_required

MotifPolicy:

flag_id, target_id, activation_mode, include_descendants, weight_multiplier

TargetHierarchy:

parent_target_id, child_target_id

CompositionConsistency (Case B rules):

composition_field, when_op, when_value, evidence_target_id, penalty_value

(If you kept Case A fields too, keep them but ignore for now.)

1.3 Validate joins (fail fast)

At load time:

Every interpretation_v2.ion_struct_id must exist in ionlist.ion_struct_id

Every MotifPolicy.target_id must exist in interpretation targets OR be a parent in TargetHierarchy

Every CompositionConsistency.evidence_target_id must exist in interpretation targets (or be expandable group parent)
